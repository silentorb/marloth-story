For most of [[01KWN86X6NJZMP5ZESZTNDXY83]]'s design I have planned on a slow, ordinary-world [[01KWN86X6NJZMP5ZESZTNDXXYA]] similar to the first book.

However, I've never been thrilled about that approach and I have occasionally considered an alternate opening which would hit the ground running with a lonely [[01KWN86X6NJZMP5ZESZTNDXY7P]] opening similar to [[01KWN86X6NJZMP5ZESZTNDXY14]].

After the latest waffling I'm leaning back to a slow start, but because this seems to be an ongoing debate, it would be good to capture the issue and motivation for my decisions here to stabilize future design.

# Motivation for an aggressive start

- Gets to the desired flavor of the story sooner
  - Though most of my ideas for this have still been a scaled down version of where the story is going

# Cons with an aggressive start

- Even if this is more aggressive, I have no interest in immediately starting at the fully fleshed out configuration the bulk of the story will take place in, so this is still only a partial acceleration
  - Because of that gap of not having the full final configuration, this needs to fill that gap with something else, and none of the something elses I've thought up so far align with the rest of the story
    - The slow start opening is classic and a well established pattern so it is effective

# Motivation for a slow start

- I want the dark, quirky side of Marloth to be the underdog, looked down on by the superior Nameless Empire
  - This is similar to what I see listening to the opening of "Lovers End" by the Birthday Massacre
  - This sets up for ultimate subversion in [[01KWN86X6MFZQAJ1V36T9592B7]]
- For [[01M3R3M8EVKRQ9A99B42S4E5GH]], it's important to introduce the noble, refined, domestic world [[01KWN86X6NJZMP5ZESZTNDXXW5]] comes from

# Cons with an slow start

- It's a little boring—I've never been that interested in it
  - There's ways to spice it up, but they don't feel integral, they feel like adding sugar to an otherwise bland food.
    - But with that said, I've rarely put serious attention toward "How can I make this more interesting", my focus for the first part has been more on reconciling it with the rest of the story, since I'm practically splicing two separate stories between the first part and the other parts
- It's a repeat of the first book's structure
  - That isn't the worst issue in the world, but it's never been my intent for such a start to be a template.
